# PrintZone

**PrintZone** es una aplicación de escritorio desarrollada para la gestión y control del inventario de una librería.

El sistema permite administrar productos, categorías, proveedores y movimientos de inventario, además de controlar el acceso mediante usuarios y roles.

## Objetivo

Facilitar el control del inventario de PrintZone, permitiendo mantener organizada la información de los productos y registrar correctamente sus entradas y salidas.

## Tecnologías

* C#
* Windows Forms
* .NET
* SQL Server
* Entity Framework Core
* Git / GitHub

## Módulos

* **Productos:** gestión y consulta de productos.
* **Categorías:** administración de categorías.
* **Proveedores:** registro y gestión de proveedores.
* **Entradas:** registro de productos que ingresan al inventario.
* **Salidas:** registro de productos que salen del inventario.
* **Usuarios:** administración de usuarios y roles.
* **Inicio de sesión:** control de acceso al sistema.

## Roles

### Administrador

Cuenta con acceso a todas las funciones administrativas del sistema.

### Vendedor

Puede consultar productos y registrar salidas de inventario.
